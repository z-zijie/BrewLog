## 记录体验优化

### 预设 + 快速确认

**目标**: 减少记录步骤

**方案**:
- 首次完整填写参数
- 之后一键复制上次参数
- 评分作为唯一必填项
- 参数可后续补充

**价值**: 3 秒完成记录

**版本**: v1.5+

---

### 内置计时器

**目标**: 冲泡时直接计时，自动填入

**方案**:
```
[开始萃取] → 计时中... → [停止]
                              ↓
                        自动填入时间
```

**价值**: 无需切换 App，数据更准确

**版本**: v1.5+

---

### 智能预测

**目标**: 自动预测用户想记录什么

**方案**:
- 根据时间预测（早上 7 点 = 意式）
- 根据历史预测（最常用参数）
- 自动填入，用户只需确认或修改

**价值**: 减少输入

**版本**: v2.0+

---

### Widget 快捷入口

**目标**: 桌面直接开始记录

**方案**:
```
┌─────────────────┐
│  ☕ 快速记录     │
│  [意式][手冲][摩卡]│
└─────────────────┘
```

**价值**: 跳过方式选择

**版本**: v2.0+

## 外购咖啡记录

### 功能概述

**目标**: 记录外面买的咖啡，形成完整咖啡生活日记

**场景**:
- 办公室点外卖咖啡
- 逛街买咖啡
- 出差喝咖啡

### 数据模型

```swift
enum RecordSource: String, Codable {
    case homemade = "自制"
    case purchased = "外购"
}

enum CoffeeBrand: String, Codable {
    case starbucks = "星巴克"
    case luckin = "瑞幸"
    case manner = "Manner"
    case timhortons = "Tims"
    case costa = "Costa"
    case independent = "独立咖啡馆"
    case other = "其他"
}
```

### 外购字段

| 字段 | 说明 |
|------|------|
| 品牌 | 星巴克/瑞幸/Manner... |
| 产品名称 | 生椰拿铁/美式... |
| 尺寸 | 大/中/小 |
| 价格 | ¥ xx |
| 照片 | 可选 |

### 快速记录

```
选择品牌 → 选择产品 → 评分 → 保存
   ↓           ↓
常用置顶    品牌下预设
```

### 统计扩展

- 本月咖啡消费金额
- 自制 vs 外购 比例
- 最常买的品牌
- 省钱报告（自制能省多少）

**版本**: v1.5+

## 数据与洞察

### 延迟记录提醒

**目标**: 不漏记

**方案**:
```
每天固定时间提醒:
"你今天喝咖啡了吗？"
[喝了] → 快速记录
[没喝] → 跳过
```

**版本**: v1.5+

---

### 深度统计分析

**目标**: 发现规律

**分析维度**:
- 时间分布（什么时候喝最多）
- 评分趋势（技术在进步吗）
- 参数相关性（什么参数评分高）
- 消费分析（花了多少钱）

**版本**: v2.0+

## 决策原则

何时加入新功能：

1. **基础功能稳定**: v1.0 核心功能无严重 Bug
2. **有真实需求**: 自己用起来觉得需要
3. **工作量可控**: 不影响核心体验
4. **有明确价值**: 解决实际问题
