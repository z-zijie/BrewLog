# BrewLog

> 咖啡冲煮参数记录 App

一款帮助咖啡爱好者记录每次冲煮参数的 iOS 应用。

---

## 简介

BrewLog 让你轻松记录意式浓缩、手冲咖啡、摩卡壶等不同冲煮方式的参数，帮助你积累经验，提升咖啡品质。

## 支持的冲煮方式

- 意式浓缩 (Espresso)
- 手冲咖啡 (Pour Over)
- 摩卡壶 (Moka Pot)

## 技术栈

| 项目 | 技术 |
|------|------|
| 平台 | iOS 15.0+ |
| 语言 | Swift |
| UI 框架 | SwiftUI |
| 数据存储 | SwiftData |
| 架构模式 | MVVM |
| 开发工具 | Xcode |

## 功能特性

- 记录冲煮参数
- 查看历史记录
- 编辑/删除记录
- 本地数据存储
- 评分与笔记
